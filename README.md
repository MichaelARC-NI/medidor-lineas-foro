# Medidor de Líneas para Foro (Vista PC) 📊

Esta es una herramienta web interactiva diseñada para ayudar a los estudiantes a verificar la extensión exacta de sus respuestas antes de publicarlas en el foro de la plataforma, asegurando el cumplimiento estricto de la regla: **mínimo 5 y máximo 8 líneas**.

## 🚀 ¿Para qué sirve?
El sistema simula en tiempo real la densidad y el ancho de un cuadro de texto de computadora estándar. Te ayuda a:
* Contar las líneas aproximadas de forma automática mientras escribes.
* Saber si tu estado es **VÁLIDO** (entre 5 y 8 líneas) o **INVÁLIDO**.
* Evitar penalizaciones por formato o extensión.

## 📱 ⚠️ ¡NOTA URGENTE PARA USUARIOS DE CELULAR!
Si abres esta página directamente desde el navegador de tu teléfono móvil, el medidor fallará y te mostrará más líneas de lo debido (por ejemplo, 15 líneas en lugar de 7) porque la pantalla es más angosta.

Para medir correctamente desde el celular, sigue estos pasos:
1. Abre el menú de opciones de tu navegador (los tres puntos arriba a la derecha en Chrome o Edge).
2. Activa la casilla **"Vista de escritorio"**, **"Sitio para computadora"** o **"Versión para ordenador"**.
3. ¡Listo! La página se recargará y medirá exactamente como si estuvieras en una PC.

## 🛠️ Funciones Especiales Integradas
* **Corrector Ortográfico:** El cuadro de texto tiene activado el atributo `spellcheck`, por lo que el navegador te subrayará en rojo cualquier falta de ortografía o acento omitido.
* **Botón de Copiado Rápido:** Una vez que tu texto esté validado y sin errores, presiona el botón 📋 **Copiar Texto** para guardarlo en tu portapapeles con un solo clic.
